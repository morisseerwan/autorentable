PACK MARCHAND AUTOMOBILE — VERSION APPLICATION

La version index.html est une application web autonome :
- Tableau de bord
- Fiche véhicule
- Suivi de tous les véhicules
- Calcul automatique du coût total, marge, marge %, ROI
- Check-list achat
- Bilan des ventes
- Sauvegarde des données dans le navigateur (localStorage)

ESSAI SUR IPHONE
1. Décompresse le ZIP.
2. Ouvre index.html avec Safari ou transfère-le sur un hébergement web.
3. Pour une vraie installation avec « Ajouter à l’écran d’accueil », l’application doit être servie depuis une adresse HTTPS.
4. Une fois ouverte sur une adresse HTTPS dans Safari : Partager → Sur l’écran d’accueil.

IMPORTANT
Les données sont enregistrées localement dans le navigateur de l’appareil. Cette version de test n'utilise pas de compte ni de serveur.
